# Changelog

All notable changes to Vectis will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-04-03

### Added

- Visual flow designer with dependency-aware pipeline orchestration
- Pipeline management with entity mapping and column-level field configuration
- Schema explorer with interactive ER diagram view
- Plugin architecture for source connectors (Dynamics 365, PostgreSQL) and destination providers (SQL Server, PostgreSQL)
- Async FastAPI backend with SQLAlchemy 2.0
- React 19 frontend with MUI 7 and React Flow
- Multi-project support with role-based access control
- Cron-based scheduling with overlap policies
- Real-time execution monitoring with run history
- JWT authentication with API key support
- Demo mode for read-only deployments
- Docker Compose setup for development and production
- Rich demo seed data with CRM and E-Commerce scenarios
